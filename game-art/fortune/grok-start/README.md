# Grok 起始图使用说明

这里的 10 张 `N-*.png` 均为 1024×1024、纯绿背景 #00B140，可直接作为相应片段的图生视频输入。

1. 选取文件名对应的起始图。
2. 打开 `grok-jobs.json`，复制该 ID 的 `full_prompt`，并按 `requested_generation_seconds` 设置时长。
3. 保留完整原视频，命名为 `N-<ID>.mp4` 对应形式，例如 `N-SHELL.mp4`，交回 `../grok-clips/`。
4. 每段视频结束时回到该起始图的姿势；循环、背景、人物位置、帽标和龟甲形状仍须逐帧检查。

## 重复起始图是刻意安排

- `N-IDLE`、`N-WELCOME`、`N-WOW`、`N-NOD`、`N-SIGH`、`N-PRINT` 共用同一张自然待机图。作揖、惊喜、点头、叹气和打印手势由视频完成。
- `N-SHELL` 和 `N-SHELL-TOSS` 共用同一张闭眼捧龟甲图，保证摇晃与抛掷的起始位置一致。
- `N-TUBE`：双拳握于胸前，身体略前倾，视线朝画面右下方，画面内无签筒。
- `N-CALC`：角色自己的左手，即观众看到的右侧手，抬到下巴旁掐指，眼睛向上看。

“没有文字”按不新增文字执行，身份所需的正向 NABO 帽标必须保留。龟甲仅用于 `N-SHELL` 和 `N-SHELL-TOSS`，其余片段不添加物体。绿底沿用牌桌抠图管线的类型；管线按边缘背景估计色值，本轮固定为 #00B140，没有继承桌沿线或旧尺寸参数。

暗底图是预览；请把本目录根部的绿底单图交给 Grok，不使用总览拼图或小尺寸预览作为视频输入。
