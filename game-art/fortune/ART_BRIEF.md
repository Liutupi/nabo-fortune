# NABO 赛博算命机 · ART BRIEF

> 美术唯一依据。Codex 和 Grok 每一轮开工前都先读这份文档。
> 动画节奏和屏幕位置以 `prototype/index.html` 为准；打开原型里的"素材框"，可以看到每个素材在屏幕上的位置和尺寸。

## 1. 硬件约束

- 屏幕 ST7789，**240×320 竖屏**，RGB565。大面积细微渐变会出现色带，所以一律平涂。
- 每个动作打包成一套 **64 色调色板**，索引 0 为透明。半透明边缘预先和背景色 **#0D0820** 混合好，固件里不做 alpha 混合。
- NABO 片段播放帧率为 **12 fps**。
- 物体运动全部交给引擎（见第 4 节），**不要画进素材**。

## 2. NABO 身份（不能改）

- 以 `nabo-idle.png` 为准：脸、眼睛、镜框、发型、白帽和帽标、比例。
- 帽标上的 NABO 字样**不能左右镜像**。需要朝左或朝右的动作，两边各做一套。
- 画风：平涂加两阶赛璐珞阴影，深色外描边（用固有色的深色，不用白描边）。
- 验收：缩到目标尺寸（76 / 100 / 120 px），放在 #0D0820 底上，要能一眼认出是 NABO，并看清表情。

## 3. 本作服装："赛博道袍"

- 深紫道袍（参考色 #4B2A9A），领口和袖口镶**青色霓虹边**（#35F0DC）。
- 可以加：胸前一枚小八卦纹章，或袖口一圈电路纹。
- 白帽和帽标保持原样。镜框不变，镜片可以带一点青色反光。
- 第 1 轮由 Codex 出 3 个方案，用户选定后锁定，以后所有素材都按这一版。

## 4. 分工

| 谁 | 负责 | 不负责 |
|---|---|---|
| **Grok** | NABO 本人的表演片段（图生视频） | 铜钱、签子、牌这类会飞的物体 |
| **Codex** | 造型定稿、Grok 用的起始图、全部静态道具、塔罗牌面、界面元素 | 逐帧动画 |
| **引擎（Claude）** | 抛掷、翻转、旋转、缩放、弹簧、转盘、震屏、粒子；抽帧、抠图、打包、校验 | — |

## 5. Grok 片段清单

所有片段的共同要求：镜头固定，**不推拉、不平移**；半身正面；纯色背景（沿用牌桌管线 `clip_to_sprites.py` 的抠图背景）；画面里**不出现**铜钱、签子、纸牌、文字。

| ID | 动作 | 时长 | 循环 | 使用尺寸 | 起始和结束姿势 |
|---|---|---|---|---|---|
| N-IDLE | 呼吸、眨眼，其中一次推眼镜 | 3 s | ✅ | 76 / 120 | 待机姿势 |
| N-WELCOME | 抱拳作揖，然后微笑 | 2 s | | 120 | 待机 → 待机 |
| N-SHELL | 双手在胸前捧龟甲上下摇，闭眼专注 | 1.5 s | ✅ | 120 | 捧龟甲 |
| N-SHELL-TOSS | 龟甲向前上方一扬，然后放回胸前 | 0.7 s | | 120 | 捧龟甲 → 捧龟甲 |
| N-TUBE | 身体前倾盯着画面外的签筒，双拳握紧期待 | 2 s | ✅ | 76 | 待机 |
| N-WOW | 惊喜：睁大眼睛，双手举起 | 1.2 s | | 76 | 待机 → 待机 |
| N-NOD | 点头微笑 | 1 s | | 76 | 待机 → 待机 |
| N-SIGH | 温和地叹口气，然后打气握拳（不能显得沮丧） | 1.4 s | | 76 | 待机 → 待机 |
| N-CALC | 抬起左手掐指计算，眼睛往上看，嘴里念念有词 | 2 s | ✅ | 56 / 100 | 掐指 |
| N-PRINT | 低头指向下方，然后竖大拇指 | 1.5 s | | 120 | 待机 → 待机 |

- **锚点**：N-SHELL 和 N-SHELL-TOSS 里，**龟甲口的位置要固定**，引擎从这里抛出铜钱。交付时在 `anchors.json` 里写明坐标（以 120 px 版为准）。
- 循环片段的首帧和尾帧必须接得上。抽帧后由引擎检查首尾差异，超过阈值就打回重做。

## 7. 塔罗牌面规则

- 每张牌都由 NABO 扮演牌中人物。愚者是背着小包的 NABO，太阳是骑着小马举旗的 NABO，以此类推。
- **构图要原创**，不能模仿任何现有塔罗牌组的画面。
- 统一边框：金色双线框，顶部放罗马数字，底部放中文牌名（牌名由引擎绘制，**牌面上不画文字**）。
- 82×135 下主体要清楚，背景元素不超过 3 个。
- 逆位不单独出图。

## 8. 交付结构

```
game-art/fortune/
  costume/        造型方案 A/B/C 和定稿 final.png
  grok-start/     每个片段的起始图（512×512 以上）
  grok-clips/     Grok 原始视频，文件名用片段 ID，如 N-SHELL.mp4
  props/          道具 PNG，按第 6 节的 ID 命名
  tarot/          00-fool.png … 21-world.png
  anchors.json    锚点坐标
```
