# 今日双色球

进入**今日一卦**，上下键选择**今日双色球**，按 OK。NABO 掐指 1.2 秒后打印小票，结果页显示 6 个升序且不重复的红球（01–33）和 1 个蓝球（01–16）。上下键循环查看号码和选号依据，OK 返回两个选项，双击上键仍回主转盘。“命签小票”保留为默认选项。

本功能是离线、个性化娱乐选号，不能预测开奖，也不提高中奖概率。不读取开奖历史，不连接投注或购买服务。“今日”指**东八区日历日期**，不代表彩票期号，也不表示今天一定开奖。使用前校准设备时间并保存生辰；如果沿用示例档案，依据页会明确标注。已打开的结果保留打印日期；日期或档案变化后，重新打印才生成对应结果。

## v1 每日固定规则

输入为当天年月日，以及已有档案的出生年月日、时辰、性别。算法支持 1901-01-01 至 2100-12-31；现有档案输入界面的较窄范围不变。无效日期、时辰、性别被拒绝。

`FortuneCore.dailySsq` 与 `fc_daily_ssq` 重新计算以下信息，不修改其他互动玩法的随机源：

- 出生与当天的农历日期、闰月标记、四柱。
- 原有每日小票：星座、星级、塔罗及正逆位、灵签签号和签级、卦象、宜忌。
- 用独立确定性随机流生成的每日幸运数字（1–9）。
- 称骨年月日时四项重量及总重。
- 紫微的命身宫、五行局、命主身主、宫干宫名、主辅星位置、亮度及四化。
- 当天**东八区 12:00**的奇门盘：阴阳遁、元、局、干支、星门神位置及值符值使落宫。

所有数字按固定顺序混合为无符号 32 位数，以版本标记 `0x53535101` 和 FNV 风格异或、乘法开始；负数哨兵值统一转为 uint32，不对 C 结构体填充字节或翻译文字做哈希。所得种子驱动独立的 mulberry32 随机流，通过拒绝采样无放回选择 6 个红球并排序，再选蓝球。原有每日小票算法和标准答案保持不变。

同一日期和档案下，重新进入、重复打印、重启、更换查看时刻、操作其他玩法，都不会换号。不同日期或档案仍可能偶然得到相同组合。未来修改算法需更换版本标记，并更新固定回归向量。

依据页显示实际使用的档案、农历日期和日干支、星座星级及幸运数、塔罗、灵签、卦象、骨重、紫微五行局和命身宫、固定午时奇门结果。这些是个性化生成的输入，不代表预测能力。号码页固定提示“娱乐选号，不预测开奖”，依据页另有“不提高中奖概率”。

## 复现验证

先安装根目录 package.json 中的开发依赖（`npm install`）。素材和渲染需要 Python 的 Pillow、numpy、fontTools；重新生成字体还需 tools/fonts 内源字体。固件字体子集保留在版本控制中，素材总包在本地生成。

```sh
python tools/gen_fonts_fortune.py
node tools/gen_fortune_text.js prototype/index.html firmware/main/fortune/fortune_text.c
./tools/validate.sh --static
# 以下固件命令需先激活 ESP-IDF v5.5.3：
./tools/validate.sh --firmware
./tools/validate.sh
```

可用 `HOST_PYTHON` 指定独立于 IDF 的宿主 Python。macOS Framework Python 应指定真实的 `Python.app/Contents/MacOS/Python` 可执行文件，让 ASan 在 Python 启动器之前加载。渲染脚本在 macOS 使用 DYLD_INSERT_LIBRARIES，在 Linux 使用 LD_PRELOAD；Windows 继续使用原有不带 sanitizer 的 PowerShell 宿主构建。

门禁覆盖原有逻辑对拍及 19 处变异测试、新增 JS/C 双色球对照、M4 音频和镜像拒绝检查、字形覆盖、ASan/UBSan 界面渲染、双色球按键与稳定性、素材句柄寿命回归。固件步骤构建、合并并校验完整 8 MB 布局与更新后的素材。本次程序版本为 **0.1.3**，不能沿用 v0.1.2 的真机验收结论。

浏览器回归独立执行，需要本地 HTTP 服务和 Playwright：

```sh
python -m http.server 8765 --bind 127.0.0.1
# 另一终端；可用 PLAYWRIGHT_MODULE、CHROMIUM_EXECUTABLE 指定运行环境：
node tests/test_ssq_browser.cjs
```

测试屏蔽远程请求，覆盖实际按键、掐指和打印、翻页、重复及刷新稳定性、洛杉矶浏览器时区下的东八区跨日、原有命签小票。截图和结果保存在被 Git 忽略的 `private/ssq-validation/`。

构建和宿主测试不证明实体屏幕、按键、声音、运行时内存、休眠或功耗。刷机需另行确认本次确切镜像及目标设备。分区布局不变；0x0 合并安装可能覆盖 NVS，布局兼容时可分段更新保留生辰。不因此获得整片擦除授权，也不套用旧版真机结果。
