## 中文使用方法

1. 安装前：确认设备为 FoloToy AI Passport（ESP32-C3，8 MB Flash）。本作是独立离线固件，会替换原程序；首次完整安装会覆盖设备原有数据，包括原固件的配网、激活等设置，请先备份。无需为本作配网。
2. 完整安装：在社区刷机工具选择本玩法固件，或从 GitHub Release 下载 nabo-fortune-v0.1.2-full.bin，通过网页工具的“本地固件刷机”从地址 0x0 写入完整镜像。不要把 app-only 文件当作完整镜像，也不要沿用其他 NABO 固件的素材偏移。下载后可用 Release 的 SHA256SUMS.txt 校验。
3. 如果已装相同分区布局的 NABO 算命机，想保留出生资料，请下载 Release ZIP，依照 docs/FLASHING.md 使用 flash_release.py 的保留 NVS 升级模式；社区完整镜像适用于首次安装。
4. 首次开机依次填写公历出生年月日、时辰和性别，再校准当前日期、时间。上、下键调整，OK 确认或进入下一项。出生资料断电保留；真正断电重开后需要重新校准时间。
5. 主转盘：上、下选择玩法，OK 进入；双击上键回主转盘（资料和时间编辑时除外）。
6. 摇卦问事 / 灵签筒：按住 OK，再松开。铜钱摇卦需完成六次投掷。解读页用上、下键翻页，OK 返回。
7. 塔罗：上、下选牌，OK 抽牌；抽出、停顿、翻面后显示放大的正位或逆位牌面，结果一直保留到再次按 OK。按 OK 重新洗牌。
8. 称骨论命：确认后观看四块砝码入盘、秤砣移动，称完会停住；按 OK 进入解读，上、下依次查看白话、原诗和骨重明细。
9. 紫微斗数可选择宫位并按 OK 看解读；奇门遁甲选择问事后看排盘与解读；星座可切换星座；今日一卦生成汇总小票。按屏幕提示操作，长内容可上下翻页。
10. 闲置五分钟自动休眠，按上键唤醒。若安装异常，先核对设备型号、固件校验值与完整安装地址，再参阅仓库刷机说明。所有结果仅供娱乐。
