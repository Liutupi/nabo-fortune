# M1 精灵帧处理记录 · 2026-10-22

工具：`tools/clip_to_sprites_fortune.py`（ffmpeg 只读 0:v:0 主视频流；源文件按 selected-clips.json 的 SHA256 校验后才处理，未改写原片）。

流程：估计实际绿底 → 软遮罩抠图 → 去绿边 → 选段（循环段自动找首尾最接近的切点；一次性动作按动作量裁剪并前后留余量）→ 24→12 fps → 预乘 alpha 面积缩放 → 半透明边缘预混合到屏幕底色 #0D0820、alpha<0.35 视为透明 → 每个动作统一 63 色 + 透明 → 时间去噪（相邻帧色差 ≤30 的像素沿用上一帧）→ FNBO v1 打包（第 0 帧关键帧 RLE，其余行差分）→ 逐帧解码回比。

## 已验证
- 10 段全部解码、抠图、打包；每帧解码结果与量化帧逐像素一致。
- 在 #0D0820 暗底上目视检查：无绿边，帽标 NABO 未镜像，循环段首尾衔接（切点误差均 < 1，0–255 色阶、60×60 缩略比较）。
- 已接入浏览器原型，所有场景实际播放。

## 未验证
- 设备上的解码速度和 SPI 带宽（M3）。
- 120/76 px 在真实 ST7789 屏上的观感（RGB565 色带、亮度）。
- N-WELCOME、N-NOD 等有意动作没有做稳像；N-TUBE 用 v2，未额外稳像。
